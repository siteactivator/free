# Бесплатные скиллы курса «AI-First SEO»

Готовые инструменты, которые можно поставить и запустить самостоятельно. У
каждого — своя папка и подробный README: что скачать, где зарегистрироваться,
как запустить.

| Скилл | Что делает |
|---|---|
| [video-review](video-review/README.md) | Вычитываете статьи на видео и голосом говорите, что поправить, — получаете список замечаний и копию статьи с пометками на тексте: что убрать, что переписать, куда дописать, какая информация нужна от вас |
| [yadisk-rescue](yadisk-rescue/README.md) | Спасает файлы с Яндекс Диска, когда у Яндекса авария хранилища: превью битые, «Скачать» висит, программа Диска не синхронизирует. Качает оригиналы через ваш браузер по одному, с паузами, чтобы не было капчи. Сохраняет страховые превью 1280 px, докачивает оборванное, продолжает после остановки. Бесплатно, без ключей и регистраций, Claude Code по желанию |
| [metrika-export](metrika-export/README.md) | Отчёты Яндекс Метрики в Excel через API — когда интерфейс не открывается или нужна выгрузка: панель с графиками, сводка со сравнением периодов, динамика, источники, поисковые фразы, реклама и UTM, страницы, цели, устройства, география. Нужен только бесплатный токен Метрики |
| [aparser](aparser/README.md) | A-Parser без его интерфейса: 43 команды на 86 рабочих парсеров — выдача и позиции в 9 поисковиках, подсказки, семантика, проверка доменов по 19 параметрам (Ahrefs, MOZ, Majestic, РКН, Whois…), доноры с оценкой линкферм (ASpamRank), тексты страниц, нейросети, карты, YouTube. Плюс 37 заготовок для непроверенных парсеров — разбирайте сами — и панель задач в браузере. Результат — Excel |

Распознавание речи — бесплатно через Groq. Для шага, где нейросеть смотрит
кадры и раскладывает замечания по тексту, нужна подписка Claude Pro или Max.

> **Для aparser нужна своя лицензия A-Parser Enterprise ($479).** Управление через
> API есть только в ней: на Lite и Pro скилл не работает. Купить —
> [a-parser.com](https://a-parser.com/?ref=21157) (реферальная ссылка автора курса).
> Ещё нужны прокси и сервис капчи — сколько всё это стоит, расписано в README
> скилла. Claude Code для него необязателен.
