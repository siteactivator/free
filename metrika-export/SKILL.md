# metrika-export — отчёты Метрики в Excel через API

API Метрики живёт отдельно от интерфейса metrika.yandex.ru: когда интерфейс не
открывается, данные забираются напрямую. Установка с нуля — `README.md`.

## Команды

Из папки скилла:

```powershell
python run.py counters                                   # счётчики, доступные токену → data\counters.xlsx
python run.py report <номер или сайт> [--days 30 | --from ГГГГ-ММ-ДД --to ГГГГ-ММ-ДД]
                     [--group day|week|month] [--only sources,phrases,...] [--top 10000] [--no-compare]
                     [--no-charts]
python run.py raw <номер или сайт> --metrics ym:s:visits,... [--dimensions ...] [--sort -ym:s:visits]
python run.py panel [--port 8790] [--data <папка с отчётами>] [--no-browser]   # http://127.0.0.1:8790/
```

`panel` — локальный сервер на 127.0.0.1: список всех `dashboard_*.html` из `data\`
и ссылки на Excel. В API не ходит, токен не нужен. Сервер живёт, пока открыт
терминал: Claude запускает его в фоне и даёт владельцу адрес.

- Токен — `METRIKA_TOKEN` в `.env` рядом с `run.py`. **Не печатать и не
  пересказывать его**; скрипт читает файл сам.
- Период по умолчанию — 30 дней по вчера; сравнение — с прошлым периодом той же
  длины.
- Файл: `data\<номер>_<сайт>\metrika_<сайт>_<начало>_<конец>.xlsx`, первым
  листом — «Панель» с графиками. Рядом — `dashboard_<сайт>_<начало>_<конец>.html`
  (та же панель, картинки встроены) и папка `charts_<начало>_<конец>` с PNG.
- Отчёт — 20–30 запросов, 20–30 секунд. Лимиты API: 5 000 запросов в сутки,
  200 отчётов за 5 минут на счётчик.

## Как отвечать владельцу

1. **Счётчик.** Если владелец назвал сайт — передать его как есть, скрипт найдёт
   счётчик по адресу. Подходит несколько — показать список и спросить. Не знает
   номер — `python run.py counters`.
2. **Период.** «За сентябрь» — `--from 2026-09-01 --to 2026-09-30`; «за
   квартал» — `--days 90`. Сравнение с прошлым периодом идёт по умолчанию.
3. **Читать Excel** — openpyxl или pandas. Строка «Итого и в среднем» — первая
   строка листа, шапка — вторая. Время на сайте хранится как доля суток (×86400 —
   секунды).
4. **Пересказ:** начать со Сводки — что выросло и упало, в процентах и
   процентных пунктах. Потом причины по листам: какой источник, поисковик,
   страница входа или устройство дали изменение. Для сравнения по листам —
   выгрузить прошлый период отдельным отчётом. В конце дать полный путь к
   `dashboard_….html`: владельцу проще открыть его, чем Excel. Картинки из
   `charts_…` можно открыть и посмотреть самому, прежде чем пересказывать.
5. **Честно о данных:**
   - лист «выборка N %» в Сводке — цифры приблизительные, так и сказать;
   - «Строк в файле» меньше «Всего в Метрике» — лист обрезан `--top`;
   - итог на листе с группировкой считается только по строкам с определённым
     значением — сумма по городам меньше всех визитов;
   - поисковые фразы поисковики в основном скрывают — по ним нельзя судить о
     всём поисковом трафике;
   - «Данные за … похоже, неполные» в выводе — последний день меньше трети
     медианы. Это недосчёт Метрики, а не обвал трафика: так и сказать и
     предложить перевыгрузить отчёт позже.

## Неочевидное

- **«Запрос слишком сложный» (400)** при перегрузке API — временное. Скрипт
  повторяет дважды с паузой, потом берёт выборку 50 % и 10 % и помечает лист.
  Проверено 12.10.2026: шесть отчётов по источникам упали с этой ошибкой и
  через минуту прошли полностью.
- Источник — последний значимый (`lastsign…`), как в интерфейсе по умолчанию.
- Типы целей переведены на русский (`GOAL_TYPES` в `run.py`); неизвестный тип
  остаётся как есть.
- Популярные страницы — из просмотров (`ym:pv:`), остальные листы — из
  визитов (`ym:s:`).
- **Панель** — `charts.py`, собирается из уже выгруженных таблиц; лишний запрос
  один — динамика прошлого периода. Нет seaborn — отчёт собирается без панели,
  ошибка в графиках не роняет Excel.
- Полосы рисуются `matplotlib.barh`, не `seaborn.barplot`: barplot усредняет
  строки с одинаковой подписью, а после сокращения адресов страниц такие бывают.
- Холсты фиксированной ширины (`layout='constrained'`, без `bbox_inches='tight'`):
  длинные подписи ужимают область графика, а не расширяют картинку, и все
  графики панели получаются в одном масштабе.
- Неполный последний день проверяется только при группировке по дням: крайние
  недели и месяцы неполные по календарю, это нормально.
