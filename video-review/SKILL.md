# video-review — замечания из видео-вычитки

Владелец читает статьи на сайте, выделяет мышью фрагменты и говорит: «вот это
убери», «откуда эти цифры», «дай ссылку на справку». Скилл превращает запись в
журнал, по которому агент фиксирует каждое замечание: статья → место в тексте →
что сказано → что сделать.

Правки на этом шаге **не вносятся**. Сначала фиксация и согласование с
владельцем, потом работа.

Всё нужное лежит в папке скилла: `run.py` и `page.py`, ключ Groq в `.env`,
результаты в `data\`. Установка с нуля — `README.md`.

## Что нужно от владельца

1. **Запись** — zip выгрузки Zoom, папка с записью или видеофайл (mp4, webm
   Телемоста, mkv, mov).
2. **Адреса страниц, которые он вычитывал**, — списком, по адресу на страницу.
   По ним `page.py` выгружает текст, и замечания ложатся на саму статью
   итоговым файлом `annotated_<slug>.html`. Без адресов остаётся только
   список замечаний по кадрам — `remarks.md`.

Если адресов не дали — спросить у владельца до выгрузки. Лист адресов
`urls_*.jpg` подскажет кандидатов: показать их списком и попросить
подтвердить. Без подтверждения по адресам с кадров не выгружать: строка адреса
на кадре бывает обрезана, а в записи мелькают и посторонние страницы — сервис,
который владелец открыл для примера, справка поисковика, поиск Google.

## Запуск

Из папки скилла:

```powershell
python run.py "<zip Zoom | видео | папка>" --project <проект> [--date 2026-09-23]
```

- вход — zip выгрузки Zoom (`recording.conf` + `video*.mp4`), папка с записью
  или сам видеофайл: mp4, webm Телемоста, mkv, mov;
- выход — `data\<проект>\<дата>_<ЧЧММ>\`, время берётся из имени записи Zoom
  («2026-09-23 23.47.13 Zoom Meeting…» → `2026-09-23_2347`) или
  Телемоста («Запись встречи 25.09.2026 13_18_12» → `2026-09-25_1318`). Если имя не как у
  Zoom — сегодняшняя дата, поэтому для других записей лучше передать `--date`.
  Две записи за день не смешаются: если папка уже занята другим исходником
  (`source.json`), скрипт остановится, а не отдаст чужой кэш;
- повторный запуск ничего не пересчитывает; пересчитать шаг —
  `--force transcript | scenes | frames`. Кадры, снятые вручную (`x_*.jpg`),
  пересчёт не трогает;
- `--width 960` — уменьшить кадры (по умолчанию как в записи: текст статьи
  должен читаться).

## Что получается

| Файл | Что в нём |
|---|---|
| `video.mp4` | исходник (из zip — распакованный) |
| `audio.mp3` | звук моно 16 кГц; больше 24 МБ — режется на куски по 20 минут |
| `transcript.json/.srt/.txt` | сегменты Whisper с абсолютным временем |
| `scenes.json` | смены экрана: `страница` (сменился весь кадр) и `переход` (сменилась полоса браузера — вкладка, адрес) |
| `utterances.json` | реплики: сегменты, склеенные по паузам короче 1 с, не длиннее 25 с |
| `frames\u_<№>_<ммсс>.jpg` | кадр на середине реплики |
| `frames\s_<№>_<ммсс>.jpg` | кадр через секунду после смены экрана |
| `frames_<№>_<ммсс>.jpg` | кадр для листа адресов: через 5 с после смены экрана или перед следующей |
| `review.md` | **журнал для агента**: время · текст · кадр, смены экрана вперемешку с репликами |
| `urls_<N>.jpg` | **лист адресов**: строка адреса браузера после каждой смены экрана с таймкодом, по 20 на лист. Одна картинка — и видно, какая статья была открыта когда |
| `source.json` | из какого файла собрана папка |
| `pages\<slug>.md/.json` | текст статьи со страницы — `page.py fetch` |
| `marks\<slug>.json` | пометки агента на тексте |
| `annotated_<slug>.html` | **итоговый файл**: статья с пометками — `page.py render` |

## Шаг агента: фиксация замечаний

0. **Сначала — адреса статей.** Если владелец не дал их вместе с записью,
   спросить сразу, до разбора, а не после списка замечаний: без них не будет
   итогового файла на тексте. Кандидатов можно показать с листа адресов
   `urls_*.jpg`, но в работу брать только подтверждённые.
1. **Прочитать `review.md` целиком и открыть листы `urls_*.jpg`.** Лист адресов
   сразу режет запись на статьи; по тексту это подтверждается — владелец
   называет статью вслух («Следующая статья. Продвижение сайта бесплатно»).
   Полоса адреса на листе снята через 5 секунд после смены экрана (или перед
   следующей сменой), когда страница уже догрузилась. Если статьи, которую
   владелец назвал вслух, на листе всё же нет — адрес читать на кадре её
   первой реплики.
2. **Смотреть кадры только там, где есть замечание** — реплики с «убери»,
   «откуда», «замени», «дай ссылку», «перепиши», а также одобрения («хорошая
   статья», «это оставляем»). Кадр открывается инструментом чтения файлов, текст
   статьи на нём читается полностью, выделение мышью видно.
3. **Если нужного момента нет среди кадров** — добрать вручную из папки записи:
   `ffmpeg -ss 00:12:17 -i video.mp4 -frames:v 1 -q:v 3 frames\x_1217.jpg`.
   Префикс `x_` — чтобы пересчёт кадров его не затёр.
4. **Сопоставить адрес со статьёй.** URL виден в адресной строке кадра. Если у
   проекта есть карта «адрес → файл исходника», владелец назовёт её — тогда в
   замечании указывать и файл.
5. **Разделить замечания на два слоя:**
   - **правила на весь проект** — владелец говорит на примере одной статьи, но
     по смыслу про все («давай вообще уберём эти подписи»). Если исходники
     статей доступны, сразу посчитать масштаб: сколько мест, в скольких файлах;
   - **точечные** — по статьям, в порядке записи.
6. **Неясное не додумывать.** Если по тексту и кадру не понятно, к чему
   замечание, — строка с пометкой «неясно» и вопрос в конце списка.
7. **Поручения тоже фиксировать** — «спроси у меня», «напомни», «покажи мне».
   Это обещания владельцу, они выполняются в конце разговора.

Результат — `remarks.md` в той же папке записи:

- таблица правил на весь проект: правило · где сказано (время и кадр) · масштаб;
- по каждой статье — URL, файл исходника (если известен), отрезок записи,
  **вердикт** (переписать / оставить / чуть поправить) и таблица: время · кадр ·
  что на экране · замечание;
- в конце — поручения и вопросы владельцу.

## Пометки на тексте страницы — `page.py`

Когда замечания по статье зафиксированы, их кладут на сам текст статьи: владелец
видит статью целиком, где подсвечено, что убрать, что переписать, куда дописать
и где нужна информация от него. Что пометить, решает агент; скачивание, поиск
цитат и вёрстка — `page.py`.

1. **Выгрузить текст страницы** — по адресу, который дал владелец (раздел
   «Что нужно от владельца»), по одной команде на страницу:

   ```powershell
   python page.py fetch <url> --session data\<проект>\<дата>_<ЧЧММ>
   ```

   В `pages\<slug>.md` — только статья: самый узкий блок страницы, где лежит
   85 % текста абзацев; меню, подвал и скрипты отброшены. Сайты за DDoS-Guard
   отдают страницу только полной строке Chrome — она зашита в скрипт.
   Повторный запуск берёт готовое, заново — `--force`. Если сайт всё равно
   отвечает 403 — попросить владельца сохранить страницу из браузера (`Ctrl+S`)
   и передать файл: `--html <путь к сохранённой странице>`.

2. **Прочитать `pages\<slug>.md` и написать `marks\<slug>.json`:**

   ```json
   {"url": "https://…", "source": "запись Телемоста 25.09.2026 13:18",
    "verdict": "чуть поправить: …",
    "marks": [
      {"action": "убрать", "quote": "точная цитата из pages/<slug>.md",
       "scope": "фрагмент", "comment": "что и почему",
       "time": "00:35", "frame": "u_003_0040"}
    ],
    "questions": ["вопрос без привязки к месту в тексте"]}
   ```

   | Поле | Значения |
   |---|---|
   | `action` | `убрать`, `переписать`, `добавить` (что дописать — в `comment`), `запросить` (что нужно от владельца, чтобы сделать правку), `уточнить` (неясное замечание), `оставить` (одобрено) |
   | `scope` | `фрагмент` — только цитата (по умолчанию); `абзац` — весь блок; `раздел` — от заголовка до следующего такого же |
   | `all` | `true` — пометить все вхождения цитаты (правило на всю статью) |
   | `time`, `frame` | где это сказано на записи |

   - **Цитата — дословно из `pages\<slug>.md`**, длинная настолько, чтобы быть
     однозначной: берётся первое вхождение. Регистр, «ёлочки» и прямые
     кавычки, длина тире и ё/е не важны.
   - **Не выдавать своё за слова владельца.** Сказанное на записи — со временем
     и кадром. Найденное по тексту по общему правилу — «на записи не показано —
     найдено по тексту». Следствия других правок — «следствие правки №…».
   - **Сверять замечание с текстом.** Если владелец сказал «про отзывы ничего
     нет», а подраздел про отзывы есть, — это `уточнить`, а не молчаливое
     «добавить».
   - `добавить` с `scope: раздел` — цитата-якорь это заголовок раздела: у
     заголовка метка «+N», блок с тем, что дописать, — в конце раздела.

3. **Собрать итоговый файл:**

   ```powershell
   python page.py render --session data\<проект>\<дата>_<ЧЧММ>
   ```

   `annotated_<slug>.html` в папке записи: вверху вердикт, счётчики по
   действиям и «Что нужно от вас» — все `запросить`, `уточнить` и `questions`
   со ссылками на места; дальше вся статья с подсветкой и комментариями.
   Цитату, которой нет в тексте, render печатает в консоли и выносит в конец
   файла — поправить цитату и собрать заново.

## Грабли

- **Whisper коверкает имена и сокращения**, даже с подсказкой терминов:
  «к.т.н.» превращается в «CTA, T.N.», фамилии авторов и названия методик
  искажаются. Такие места сверять по кадру и по смыслу, а неочевидные — выносить
  в вопросы. Словарь подсказки — константа `PROMPT` в `run.py`, пополнять по
  мере находок.
- **Переход «белая страница → белая страница» весь кадр не ловит.** Поэтому
  второй детектор смотрит только на полосу браузера сверху (13 % высоты, порог
  0,04). Если запись не браузерная или окно маленькое — пороги `NAV_STRIP` и
  `SCENE_NAV` нужно перекалибровать: оценки лежат в `_scores_nav.txt`. Строка
  адреса для листов — `ADDR_BOX`, откалибрована на окне Chrome 1440×932.
- **Долгое молчание — не пустота.** Владелец читает молча минутами, и реплика
  в 20 секунд может быть одним словом («50»). Смотреть кадр и соседние реплики.
- **Сайты за DDoS-Guard** отдают 403 на урезанную строку браузера
  `Mozilla/5.0`. Для сверки со страницей — полная строка Chrome.
- **Whisper дописывает на тишине несуществующие фразы** — «Субтитры создавал
  DimaTorzok», «Продолжение следует», «Корректор А.Егорова». Такие сегменты
  отсекаются регуляркой `HALLUCINATIONS`; новые находки добавлять туда, но
  узко: сегмент с совпадением выбрасывается целиком, вместе с настоящей речью.
- **Архив Zoom без видео.** Если выгрузить папку записи, пока Zoom конвертирует
  или облако не догрузило файл, в zip попадёт один `recording.conf` (архив в
  полкилобайта). Скрипт скажет об этом прямо.
- **Zoom может записать звук отдельно** (`audio*.m4a` в `recording.conf`). Если в
  видео нет звуковой дорожки, скрипт остановится и скажет об этом — положите
  m4a рядом и передайте папку.
