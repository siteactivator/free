# Замечания к статьям из видео: скилл video-review

Вы открываете свои статьи в браузере, листаете их, выделяете мышью фрагменты и
говорите вслух: «вот это убери», «откуда эти цифры», «здесь дай ссылку на
источник». Записываете это на видео. Скилл превращает запись в **список
замечаний**: какая статья, какое место в тексте, что вы сказали, что нужно
сделать. А если дать ещё и адреса страниц — **копию статьи с пометками прямо
на тексте**: что убрать, что переписать, куда дописать и какая информация
нужна от вас.

Больше не нужно печатать замечания руками и объяснять, к какому абзацу относится
«вот это». Нейросеть сама смотрит кадр и видит, какой фрагмент вы выделили.

## Как это работает

Работа идёт в три этапа.

**Этап 1 — скрипт `run.py`** (бесплатно, на вашем компьютере и в Groq):

1. Достаёт звук из видео и отправляет его в Groq — бесплатный сервис
   распознавания речи на модели Whisper. Обратно приходит текст с точным
   временем каждой фразы.
2. Программа ffmpeg находит моменты, когда на экране сменилась страница или
   адрес в браузере.
3. На середине каждой вашей фразы и после каждой смены экрана сохраняется
   кадр — снимок экрана в этот момент.
4. Всё собирается в журнал `review.md`: время → что вы сказали → кадр. И в
   листы адресов `urls_*.jpg`: одна картинка, где видно, какая статья была
   открыта в какую минуту.

**Этап 2 — агент Claude Code** (по подписке Claude):

5. Claude читает журнал, открывает кадры в местах замечаний, видит выделенный
   мышью текст и пишет `remarks.md` — таблицу замечаний по каждой статье, общие
   правила для всех статей и вопросы к вам, если что-то неясно.

**Этап 3 — пометки на тексте** (скрипт `page.py` и Claude Code):

6. По адресам, которые вы дали, скрипт скачивает статьи с сайта — только текст,
   без меню и подвала.
7. Claude раскладывает замечания по тексту: точная цитата → что с ней сделать.
8. Скрипт собирает итоговый файл `annotated_<статья>.html`: вся статья, нужные
   места подсвечены цветом, рядом комментарии, вверху — что нужно от вас.

Правки в статьи на этих шагах **не вносятся**. Сначала вы читаете список и
соглашаетесь с ним, потом можно просить Claude вносить правки.

**Скорость:** 20 минут записи обрабатываются за 2–3 минуты, плюс несколько
минут на шаг агента.

## Что понадобится и сколько стоит

| Что | Зачем | Стоимость |
|---|---|---|
| Компьютер на Windows 10/11 или macOS 13+ | всё работает на нём | — |
| Python 3.10 или новее | запускает скрипт | бесплатно |
| ffmpeg | режет видео на кадры и достаёт звук | бесплатно |
| Аккаунт Groq | распознаёт речь | бесплатно, без карты |
| Zoom, Яндекс Телемост, OBS Studio или встроенная запись экрана | записать вычитку | бесплатно |
| Claude Code | составляет список замечаний по кадрам | нужна подписка Claude Pro или Max ([цены](https://claude.com/pricing)); на бесплатном плане Claude Code недоступен |

Этап 1 полностью бесплатный. Если подписки Claude нет, журнал `review.md` с
кадрами всё равно пригодится: его можно читать самому или отдать другому
агенту, который умеет смотреть картинки.

**Перед началом:** все команды ниже вводятся в терминале.

- **Windows:** нажмите `Win`, наберите `PowerShell`, нажмите Enter. Строка
  начинается с `PS C:\Users\ВашеИмя>`.
- **macOS:** `Cmd + Пробел`, наберите `Терминал`, нажмите Enter.

Команду копируете, вставляете в окно терминала (правая кнопка мыши или
`Ctrl + V`) и нажимаете Enter.

## Шаг 1. Python

### Windows

1. Откройте [python.org/downloads](https://www.python.org/downloads/) и нажмите
   жёлтую кнопку **Download Python 3.x**.
2. Запустите скачанный файл.
3. **Важно:** на первом экране установщика поставьте галочку
   **Add python.exe to PATH** внизу окна. Без неё команда `python` не будет
   работать.
4. Нажмите **Install Now** и дождитесь окончания.
5. **Закройте и заново откройте PowerShell** — новые программы видны только в
   новых окнах.

Другой способ — одной командой в PowerShell:

```powershell
winget install -e --id Python.Python.3.12
```

**Проверка:**

```powershell
python --version
```

Должно появиться `Python 3.12.x` или похожее, 3.10 и выше.

> **Если вместо версии открылся Microsoft Store** — Windows подставляет свою
> заглушку. Откройте **Параметры → Приложения → Дополнительные параметры
> приложений → Псевдонимы выполнения приложений** и выключите переключатели
> `python.exe` и `python3.exe`. Потом откройте PowerShell заново.

### macOS

1. Установите Homebrew — менеджер программ для Mac. Команда с сайта
   [brew.sh](https://brew.sh):

   ```bash
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   ```

   В конце установщик покажет две-три команды «Next steps» — выполните их.
2. Установите Python:

   ```bash
   brew install python
   ```

3. Проверка: `python3 --version`.

> На macOS везде ниже пишите `python3` вместо `python`.

## Шаг 2. ffmpeg

ffmpeg — бесплатная программа для работы с видео. Скрипт вызывает её, чтобы
достать звук и нарезать кадры.

### Windows

Одной командой в PowerShell:

```powershell
winget install Gyan.FFmpeg
```

Если `winget` не найден или установка не прошла — вручную:

1. Откройте [gyan.dev/ffmpeg/builds](https://www.gyan.dev/ffmpeg/builds/),
   в разделе **release builds** скачайте `ffmpeg-release-essentials.zip`.
2. Распакуйте архив и переименуйте папку в `ffmpeg`, положите её в корень диска:
   `C:\ffmpeg`. Внутри должна быть папка `C:\ffmpeg\bin` с файлами
   `ffmpeg.exe` и `ffprobe.exe`.
3. Добавьте её в PATH: нажмите `Win`, наберите **«Изменение системных
   переменных среды»** → кнопка **Переменные среды** → в верхнем списке
   выберите **Path** → **Изменить** → **Создать** → впишите `C:\ffmpeg\bin` →
   **ОК** во всех окнах.

**Закройте и заново откройте PowerShell**, затем проверьте:

```powershell
ffmpeg -version
ffprobe -version
```

Обе команды должны вывести `ffmpeg version …`, а не ошибку.

### macOS

```bash
brew install ffmpeg
```

Проверка: `ffmpeg -version`.

## Шаг 3. Папка скилла и библиотеки

1. Скопируйте папку `video-review` в удобное место. Лучше путь **без
   кириллицы и пробелов**, например `C:\video-review` — так меньше шансов
   наткнуться на ошибки в сторонних программах.

   В папке лежат:

   | Файл | Что это |
   |---|---|
   | `run.py` | скрипт этапа 1 |
   | `page.py` | скрипт этапа 3: текст страницы и итоговый файл с пометками |
   | `SKILL.md` | инструкция для агента на этапе 2 |
   | `README.md` | этот файл |
   | `requirements.txt` | список библиотек Python |
   | `.env.example` | образец файла с ключом |
   | `.gitignore` | чтобы ключ и записи не попали в git |

2. Откройте терминал **в этой папке**:
   - **Windows 11:** откройте папку в Проводнике, нажмите правой кнопкой по
     пустому месту → **Открыть в терминале**.
   - **Windows 10:** в Проводнике кликните в адресную строку папки, наберите
     `powershell` и нажмите Enter.
   - Или командой: `cd C:\video-review`
   - **macOS:** `cd ~/video-review` (путь к вашей папке).

3. Установите библиотеки:

   ```powershell
   python -m pip install -r requirements.txt
   ```

   Ставятся две библиотеки: `requests` — для обращения к Groq и `Pillow` — для
   листов адресов. В конце должно быть `Successfully installed …` или
   `Requirement already satisfied`.

## Шаг 4. Бесплатный ключ Groq для распознавания речи

Groq — облачный сервис, который бесплатно распознаёт речь моделью Whisper
large v3 turbo. Карта не нужна.

### Регистрация и ключ

1. Откройте [console.groq.com](https://console.groq.com) и нажмите
   **Sign in** / **Log in**. Войти можно через Google, GitHub или по почте
   (придёт письмо со ссылкой для входа).
2. После входа откройте раздел **API Keys** в левом меню или сразу
   [console.groq.com/keys](https://console.groq.com/keys).
3. Нажмите **Create API Key**, придумайте название (например `video-review`) и
   нажмите **Submit**.
4. **Сразу скопируйте ключ** — он начинается с `gsk_`. Groq показывает его один
   раз; если закрыли окно, просто создайте новый ключ.

### Файл с ключом

Ключ хранится в файле `.env` в папке скилла. В PowerShell, находясь в папке
скилла:

```powershell
Copy-Item .env.example .env
notepad .env
```

В Блокноте после `GROQ_API_KEY=` вставьте ключ без пробелов и кавычек:

```
GROQ_API_KEY=gsk_ваш_ключ
```

Сохраните (`Ctrl + S`) и закройте.

На macOS: `cp .env.example .env && open -e .env`.

> **Ловушка Блокнота.** Если создавать файл через «Сохранить как», Блокнот
> добавляет `.txt`, и получается `.env.txt` — скрипт его не увидит. Команда
> `Copy-Item` выше этой проблемы не имеет. Проверить имя: `dir -Force` —
> должен быть файл `.env` без `.txt`.

> **Никому не пересылайте файл `.env`** и не выкладывайте его в интернет. Если
> ключ утёк — удалите его на странице API Keys и создайте новый.

### Лимиты бесплатного тарифа

| Ограничение | Значение | Что это значит |
|---|---|---|
| Размер одного файла | 25 МБ | скрипт сам режет звук на куски по 20 минут; час записи — около 21 МБ, обычно хватает одного запроса |
| Звука в час | 7 200 секунд | 2 часа записи в час |
| Звука в сутки | 28 800 секунд | 8 часов записи в сутки |
| Запросов | 20 в минуту, 2 000 в сутки | для этого скилла не заметно |

Если лимит кончился, Groq отвечает «подождите», и скрипт ждёт сам — в консоли
появится `лимит Groq, жду N с…`.

> Если сайт Groq не открывается или регистрация не проходит — сервис доступен
> не во всех странах. Проверьте, открывается ли
> [console.groq.com](https://console.groq.com) из вашей сети.

## Шаг 5. Claude Code

Claude Code — агент от Anthropic, который работает в терминале: читает файлы,
смотрит картинки и пишет результат в файлы. На этапе 2 он составляет список
замечаний.

### Подписка

Нужен аккаунт Claude с подпиской **Pro или Max** (или Team/Enterprise, или
платный аккаунт Console с оплатой по API). **На бесплатном плане claude.ai
Claude Code не работает.** Оформить — [claude.ai](https://claude.ai) → аватар →
**Upgrade**. Сервис доступен не во всех странах:
[список стран](https://www.anthropic.com/supported-countries).

### Установка

**Windows (PowerShell):**

```powershell
irm https://claude.ai/install.ps1 | iex
```

Или через winget: `winget install Anthropic.ClaudeCode`

Права администратора не нужны. Рекомендуется также поставить
[Git для Windows](https://git-scm.com/downloads/win) — с ним Claude Code
увереннее выполняет команды, но и без него работает.

**macOS:**

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Закройте и откройте терминал заново, затем проверьте:

```powershell
claude --version
```

Должна появиться версия, например `2.1.211 (Claude Code)`. Если что-то не
так — команда `claude doctor` покажет, в чём проблема.

### Вход

1. В терминале наберите `claude` и нажмите Enter.
2. Выберите способ входа — **Claude account with subscription** (аккаунт с
   подпиской).
3. Откроется браузер — войдите в свой аккаунт claude.ai и подтвердите доступ.
4. Вернитесь в терминал: Claude Code готов к работе. Выйти из сессии —
   `/exit` или дважды `Ctrl + C`.

Входить нужно один раз, дальше Claude Code помнит аккаунт.

> Не любите терминал? Есть приложение Claude для компьютера с Claude Code
> внутри: [claude.com/download](https://claude.com/download). В нём откройте
> папку скилла и дайте ту же просьбу, что в шаге 8.

## Шаг 6. Как записать видео

### Как вести вычитку, чтобы нейросеть всё поняла

- **Браузер — Chrome, окно развёрнуто, масштаб 100 %.** Адресную строку не
  прячьте: по ней скрипт узнаёт, какая статья открыта.
- **Называйте статью вслух**, когда открываете её: «Следующая статья —
  продвижение сайта бесплатно».
- **Сначала выделите мышью фрагмент, потом говорите.** Кадр снимается в
  середине вашей фразы — выделение должно быть на экране, пока вы говорите.
- **Говорите глаголами:** «убери», «замени на…», «перепиши проще», «дай
  ссылку на источник», «откуда эти цифры», «это оставляем», «хорошая статья».
- **Делайте паузу 1–2 секунды между замечаниями.** Паузы короче секунды
  склеивают фразы в одну реплику.
- **Общее правило говорите явно:** «и так во всех статьях — уберём эти
  подписи». Агент вынесет его отдельно и посчитает, сколько таких мест.
- **Поручения тоже говорите вслух:** «напомни мне…», «спроси меня потом…» —
  они попадут в конец списка.
- **Запишите адреса статей, которые вычитываете**, — списком, по одному на
  статью. Они понадобятся на шаге 9, чтобы положить пометки на текст.
- **Не показывайте пароли и личные данные**: кадры и звук уходят в облачные
  сервисы (см. [Куда уходят ваши данные](#куда-уходят-ваши-данные)).

### Вариант А: Zoom

Подходит бесплатный аккаунт Zoom и программа Zoom для компьютера
([zoom.us/download](https://zoom.us/download)).

1. Запустите Zoom, войдите в аккаунт, нажмите **Новая конференция** (New
   meeting). В конференции будете только вы. Камеру можно выключить.
2. Проверьте, что микрофон включён (значок микрофона не перечёркнут).
3. Нажмите **Демонстрация экрана** (Share Screen) → выберите **окно Chrome**
   со статьёй → **Демонстрация**.
4. Нажмите **Запись → Записывать на этот компьютер** (Record on this
   computer). В облако не нужно.
5. Проведите вычитку.
6. Нажмите **Остановить запись**, затем **Завершить конференцию**.
7. Zoom **конвертирует запись** — дождитесь окончания, это займёт от минуты до
   нескольких. После этого откроется папка записи. По умолчанию это
   `Документы\Zoom\<дата время> Zoom Meeting`, например
   `C:\Users\ВашеИмя\Documents\Zoom\2026-09-23 23.47.13 Zoom Meeting`. Внутри —
   файл `.mp4`.

Скрипту можно передать эту папку целиком: он сам возьмёт видео, а дату и время
возьмёт из имени папки. Если папка синхронизируется в облако и вы скачали её
zip-архивом — передавайте zip.

> На бесплатном Zoom конференция может ограничиваться 40 минутами. Для
> длинной вычитки делайте несколько записей — каждая разбирается отдельно.

### Вариант Б: OBS Studio

Бесплатная программа записи экрана: [obsproject.com](https://obsproject.com).

1. Установите и запустите OBS. Мастер автонастройки можно пропустить.
2. В окне **Источники** нажмите **+** → **Захват окна** (Window Capture) →
   выберите окно Chrome.
3. В **Микшере аудио** проверьте, что **Mic/Aux** (микрофон) двигает шкалу,
   когда вы говорите.
4. **Настройки → Вывод → Запись → Формат записи — mp4** (по умолчанию может
   стоять mkv).
5. **Начать запись**, провести вычитку, **Остановить запись**. Файл окажется в
   папке «Видео», путь видно в **Настройки → Вывод → Путь записи**.

Такому файлу имя не как у Zoom, поэтому при запуске передайте дату:
`--date 2026-09-23`.

### Вариант В: Яндекс Телемост

Бесплатно, в браузере: [telemost.yandex.ru](https://telemost.yandex.ru).

1. Создайте встречу, включите микрофон. Камеру можно выключить.
2. Включите демонстрацию экрана — весь экран или окно Chrome.
3. Включите запись встречи и проведите вычитку.
4. Остановите запись и завершите встречу. Телемост сохранит файл вида
   `Запись встречи 25.09.2026 13_18_12.webm` — ищите его в папке «Загрузки».

Скрипту передайте этот файл: формат `.webm` он принимает, дату и время
возьмёт из имени сам. Проверено на записи всего экрана 1920×1080: адресная
строка распознаётся без настройки, плашка «Приложению telemost.yandex.ru
предоставлен доступ к вашему экрану» внизу кадра не мешает.

### Вариант Г: встроенная запись macOS

`Cmd + Shift + 5` → **Записать выбранную часть экрана** → **Параметры** →
в разделе микрофона выберите **встроенный микрофон** → **Записать**. Файл
`.mov` появится на рабочем столе. Скрипт его примет, дату передайте через
`--date`.

## Шаг 7. Запуск скрипта

Откройте терминал в папке скилла (шаг 3) и выполните:

```powershell
python run.py "C:\Users\ВашеИмя\Documents\Zoom\2026-09-23 23.47.13 Zoom Meeting" --project my-site
```

- В кавычках — путь к записи: папка Zoom, zip-архив или видеофайл (`.mp4`,
  `.webm` из Телемоста, `.mkv`, `.mov`). **Путь с
  пробелами обязательно в кавычках.** Подсказка: перетащите папку или файл
  мышью в окно терминала — путь вставится сам.
- `--project my-site` — название проекта, латиницей. Записи разных сайтов
  лягут в разные папки. Можно не указывать — будет `my-site`.
- Дату и время скрипт берёт из имени записи Zoom или Телемоста. Для других
  записей добавьте дату сами: `--date 2026-09-23`.

✅ распознано сегментов: 104

### Что появилось в папке записи

`data\<проект>\<дата>_<ЧЧММ>\`:

| Файл | Что в нём |
|---|---|
| `review.md` | **главное**: журнал — время, ваши слова, ссылка на кадр |
| `urls_1.jpg`, `urls_2.jpg` … | адресные строки браузера с таймкодами — какая статья когда была открыта |
| `frames\` | кадры: `u_…` — на середине каждой фразы, `s_…` — после смены экрана, `a_…` — для листов адресов |
| `transcript.txt` | весь текст речи с таймкодами — удобно просто почитать |
| `transcript.srt` | субтитры: можно подключить к видео в плеере |
| `video.mp4`, `audio.mp3` | копия видео и звук |
| `*.json` | данные для агента |

**Откройте `urls_1.jpg`** — там должны быть видны адреса страниц. Если на
картинке не адресная строка, а кусок страницы — поправьте область
(см. [Настройка под себя](#настройка-под-себя)).

### Повторный запуск

Скрипт ничего не делает повторно: второй запуск той же команды пройдёт за
секунды. Чтобы пересчитать отдельный шаг:

```powershell
python run.py "<та же запись>" --project my-site --force transcript   # заново распознать речь
python run.py "<та же запись>" --project my-site --force scenes       # заново найти смены экрана
python run.py "<та же запись>" --project my-site --force frames       # заново нарезать кадры
```

Другие параметры: `--language en` — если говорите не по-русски; `--width 960` —
кадры поменьше, если экран очень большой.

## Шаг 8. Список замечаний — шаг агента

1. Откройте терминал в папке скилла и запустите Claude Code:

   ```powershell
   claude
   ```

   При первом запуске в папке он спросит, доверяете ли вы ей, — ответьте
   **Yes**.

2. Напишите просьбу (путь к записи — из вывода скрипта):

   ```
   Прочитай SKILL.md и разбери запись data\my-site\2026-09-23_2347:
   прочитай review.md, открой листы urls_*.jpg и кадры в местах замечаний
   и составь remarks.md по шагам из SKILL.md. Ничего не правь, только зафиксируй.
   ```

3. Claude будет спрашивать разрешение прочитать файлы или запустить ffmpeg,
   чтобы добрать кадр, — разрешайте (**Yes**).

4. Результат — `data\my-site\2026-09-23_2347\remarks.md`:
   - **правила на весь проект** — то, что вы сказали про все статьи сразу;
   - **по каждой статье** — адрес, вердикт (переписать / оставить / чуть
     поправить) и таблица: время → кадр → что на экране → замечание;
   - **вопросы к вам** — места, где по записи не понятно, что имелось в виду;
   - **ваши поручения** — «напомни», «спроси».

5. Прочитайте список, ответьте на вопросы, поправьте, если нужно. После этого
   можно попросить Claude вносить правки в статьи — уже осознанно, по
   согласованному списку.

> **Совет.** Если исходники статей лежат у вас в файлах (например, `.md` или
> `.docx`), скажите Claude, где они: он укажет в замечаниях конкретный файл и
> посчитает, сколько мест затрагивает каждое общее правило.

### Чтобы Claude Code сам узнавал этот скилл

Необязательно. Если скопировать папку `video-review` в
`C:\Users\ВашеИмя\.claude\skills\video-review` (на Mac —
`~/.claude/skills/video-review`), Claude Code будет видеть скилл в любой
папке: достаточно сказать «разбери видео-вычитку …». Результаты тогда будут
складываться в `data\` внутри этой папки.

Дальше — [шаг 9](#шаг-9-пометки-на-тексте-статьи): итоговый файл с пометками
прямо на тексте статьи.

## Шаг 9. Пометки на тексте статьи

Итог всей работы — копия статьи, на которой сразу видно, что делать:
фрагмент зачёркнут — убрать, подсвечен жёлтым — переписать, в рамке — что
дописать, синим — где нужна информация от вас. Не надо сопоставлять список
замечаний со статьёй: всё уже на своих местах.

### Что нужно

- папка записи после шагов 7 и 8;
- **адреса страниц, которые вы вычитывали**, — по одному на статью.

Без адресов этот шаг не сделать. Если адреса не назвать, Claude предложит
их сам — с листа адресов `urls_*.jpg` — и выгрузит только после вашего
подтверждения: на записи мелькают и посторонние страницы, а строка адреса на
кадре бывает обрезана.

### Как попросить Claude Code

В той же сессии Claude Code, что на шаге 8, напишите:

```
Сделай итоговые файлы с пометками по SKILL.md для этих страниц:
https://site.ru/blog/statya-1
https://site.ru/blog/statya-2
Запись — data\my-site\2026-09-23_2347.
```

Для каждой страницы Claude сделает три шага:

1. Скачает страницу и оставит только текст статьи:

   ```powershell
   python page.py fetch https://site.ru/blog/statya-1 --session data\my-site\2026-09-23_2347
   ```

   Текст ляжет в `pages\statya-1.md` в папке записи.
2. Разложит замечания по тексту в `marks\statya-1.json`: точная цитата из
   статьи, действие, комментарий, время и кадр на записи.
3. Соберёт итоговый файл:

   ```powershell
   python page.py render --session data\my-site\2026-09-23_2347
   ```

Те же команды можно запускать и самому — например, чтобы пересобрать файл после
того, как вы поправили пометки.

### Итоговый файл

`data\my-site\2026-09-23_2347\annotated_statya-1.html` — откройте двойным
щелчком, он откроется в браузере.

- **Вверху** — вердикт по статье, сколько каких пометок и блок **«Что нужно от
  вас»**: вопросы и запросы информации, каждый со ссылкой на место в тексте.
  Ответьте на них — без этого часть правок не сделать.
- **Дальше** — вся статья с пометками:

| Как выглядит | Что значит |
|---|---|
| красный фон, текст зачёркнут | убрать |
| жёлтый фон | переписать |
| метка «+N» у заголовка и зелёная пунктирная рамка | добавить: что дописать и куда |
| синий фон | нужна информация от вас |
| фиолетовый фон | уточнить: замечание неясно, вопрос к вам |
| бледно-зелёный фон | оставить: вы это одобрили |

У каждой пометки — номер, ваша фраза с записи, время и кадр. Если Claude нашёл
то же самое по тексту сам — например, вы показали одну неудачную формулировку,
а в статье их ещё три, — пометка так и подписана: «на записи не показано —
найдено по тексту». Свои догадки за ваши слова он не выдаёт.

Файл можно распечатать или сохранить в PDF: в браузере `Ctrl + P`.

> Пометки — это не правки: статья на сайте не меняется. Прочитайте файл,
> ответьте на вопросы, и только потом просите Claude вносить правки.

## Настройка под себя

Все настройки — константы в начале `run.py`. Откройте его в любом редакторе
(Блокнот, VS Code).

| Константа | Что меняет | Когда трогать |
|---|---|---|
| `PROMPT` | подсказка для распознавания: тема и термины | вы вычитываете не SEO-статьи, или Whisper коверкает ваши термины, бренды, фамилии. Впишите их через запятую; предел — около 150 слов |
| `ADDR_BOX` | где на кадре адресная строка, для листов `urls_*.jpg` | на листах видна не адресная строка |
| `ADDR_DELAY` | через сколько секунд после смены экрана снимать адрес для листов (по умолчанию 5) | сайт грузится медленно и на листе остаётся прежний адрес — увеличьте |
| `NAV_STRIP`, `SCENE_NAV` | детектор смены вкладки или адреса | скрипт пропускает переходы между статьями или видит лишние |
| `SCENE_PAGE` | детектор смены всей страницы | то же, для смены страницы целиком |
| `HALLUCINATIONS` | фразы, которые Whisper выдумывает на тишине | в тексте появилась фраза, которую вы не говорили («Спасибо за просмотр») |

### Как настроить `ADDR_BOX`

1. Откройте любой кадр `frames\s_001_….jpg` в Paint.
2. Наведите мышь на левый верхний угол адресной строки — внизу окна Paint
   видны координаты в пикселях. Запишите их, потом координаты правого нижнего
   угла.
3. Разделите: X — на ширину кадра, Y — на высоту. Размер кадра скрипт печатает
   при запуске, например `1440×932`.
4. Впишите четыре доли в `ADDR_BOX = (слева, сверху, справа, снизу)`, например
   `(0.0, 0.055, 0.62, 0.125)`.
5. Запустите скрипт той же командой — листы адресов пересоберутся, остальное
   возьмётся из готового.

После изменения `NAV_STRIP`, `SCENE_NAV` или `SCENE_PAGE` запускайте с
`--force scenes frames`. Оценки каждой секунды записи лежат в
`_scores_full.txt` и `_scores_nav.txt` — по ним видно, какой порог нужен.

## Частые ошибки

| Что видите | Что делать |
|---|---|
| `python : Имя "python" не распознано…` или открылся Microsoft Store | Python не установлен или не в PATH — шаг 1, галочка **Add python.exe to PATH**, потом отключить псевдонимы Store |
| `Не найдено: ffmpeg, ffprobe` | шаг 2, и **откройте терминал заново** |
| `Нет библиотеки requests` | в папке скилла: `python -m pip install -r requirements.txt` |
| `[notice] A new release of pip available` после установки библиотек | это не ошибка, pip предлагает обновиться. Библиотеки установлены, если выше есть `Successfully installed` |
| `GROQ_API_KEY не найден` | нет файла `.env` рядом с `run.py`, или он называется `.env.txt` — шаг 4 |
| `Groq 401: ключ не подошёл` | ключ скопирован не полностью или удалён — создайте новый на [console.groq.com/keys](https://console.groq.com/keys) |
| `лимит Groq, жду N с…` | это не ошибка, скрипт подождёт сам. Если так весь день — исчерпан суточный лимит в 8 часов звука, продолжите завтра |
| `Groq недоступен` | проверьте интернет и что [console.groq.com](https://console.groq.com) открывается в браузере |
| `Файл не найден` | путь с ошибкой или без кавычек; перетащите файл мышью в окно терминала |
| `В архиве нет .mp4, только ['…recording.conf']` | Zoom ещё конвертирует запись или облако не догрузило видео — подождите и выгрузите заново |
| `В видео нет звуковой дорожки` | микрофон не записался. Zoom иногда пишет звук отдельным файлом `audio….m4a` — передайте папку записи целиком. В OBS проверьте источник Mic/Aux |
| `Папка … уже занята другой записью` | две записи попали в одну папку — добавьте `--date 2026-09-23_2` |
| На листах `urls_*.jpg` не адреса | настройте `ADDR_BOX` |
| В тексте искажены термины и фамилии | добавьте их в `PROMPT` и запустите с `--force transcript` |
| Кракозябры вместо русских букв в терминале | выполните `chcp 65001` и запустите снова |
| `claude : Имя "claude" не распознано…` | откройте терминал заново после установки; не помогло — `claude doctor` или переустановка через `winget install Anthropic.ClaudeCode` |
| Claude Code просит войти или пишет про подписку | нужен план Pro или Max — шаг 5 |
| `page.py`: `… ответил 403` | сайт не отдаёт страницу скрипту: защита от ботов. Откройте страницу в браузере, сохраните её (`Ctrl + S`) и передайте файл: `python page.py fetch <адрес> --session … --html "C:\путь\страница.html"` |
| `page.py`: `Текст статьи не найден` | страница собирается скриптами прямо в браузере — такой сайт этот шаг не поддерживает |
| `⚠ не привязано: …` и блок «Не удалось привязать к тексту» в конце файла | цитаты нет в тексте: страница изменилась после записи или цитата неточная. Попросите Claude поправить цитату и собрать файл заново |

## Куда уходят ваши данные

- **Видео** остаётся на вашем компьютере, в папке `data\`.
- **Звук** (`audio.mp3`) отправляется в Groq для распознавания.
- **Кадры и текст**, которые открывает Claude Code на шагах 8 и 9,
  отправляются в Anthropic — так нейросеть их видит.
- **Текст статей** скачивается с вашего сайта и хранится в папке записи,
  в `pages\`.
- **Ключ Groq** лежит только в `.env` у вас. Файл `.gitignore` не даёт ему и
  папке `data\` попасть в git-репозиторий, если вы выложите скилл на GitHub.

Не записывайте в вычитке пароли, личные данные клиентов и закрытые документы.
